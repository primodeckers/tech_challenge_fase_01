1) RESUMO DO PROJETO
--------------------------------------------------------------------------------
Objetivo: modelar churn (cancelamento) em telecomunicações com o dataset
Telco Customer Churn (Excel), priorizando métricas adequadas à classe minoritária
(PR-AUC, F1) e um limiar de decisão documentado (ver docs/metricas_e_limiar.md).

Fluxo técnico:
  • EDA e limpeza (Total Charges, remoção de leakage — ex. Churn Score, CLTV)
  • Baselines Scikit-learn: Dummy, regressão logística, Random Forest; mesmo
    pré-processamento (ColumnTransformer); validação cruzada estratificada;
    tracking no MLflow (runs, métricas por fold, out-of-fold para F1 no limiar)
  • MLP em PyTorch (notebook 03), early stopping, pos_weight; métricas no MLflow
  • API FastAPI: GET /health, POST /predict; validação Pydantic; testes pytest;
    modelo servido = pipeline sklearn exportado da regressão logística (rápido,
    mesmo pré-processamento dos notebooks)
  • Deploy opcional em Google Cloud Run (Docker); artefacto pipeline.joblib não
    vai no Git — gerar com scripts/export_logistic_artifact.py antes do build
